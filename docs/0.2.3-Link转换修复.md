# 0.2.3：超量怪兽切换为连接怪兽的生成修复

MDPro3 数据库对象的 LinkMarker 字段可能在非连接怪兽上保留原守备力。编辑器原先无条件读取该字段，导致霍普的 2000 守备力被当作连接箭头，其中不可见的无效位会触发核心的参数错误。

现在只有连接怪兽才读取连接箭头；读取已有卡片及提交自定义形态时统一保留八个有效方向。连接数按有效箭头数量计算，隐藏的阶级和守备力输入不再参与连接形态的数值校验。

验证：实际 MDPro3 界面中选取希望皇霍普，将阶级从 4 改为 5，切换连接、勾选左上箭头并生成，成功得到连接数 1 的怪兽。两个运行框架下均通过 80 项核心断言，包括非连接卡片守备力隔离、箭头掩码、类型转换与回溯恢复。

YGOPro 的数据库读取逻辑已区分守备力和连接箭头，本次没有发现同一处缺陷，因此未改动 YGOPro 客户端。

Mono 扩展已同步构建，完整 Mono 本体游戏启动仍待目标机器验证。
