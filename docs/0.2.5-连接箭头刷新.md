# 0.2.5：自定义连接箭头的场面刷新

核心已正确保存自定义箭头，但 MDPro3 的默认怪兽刷新请求未包含 QUERY_LINK（连接数和连接箭头）。客户端继续保留原卡的 LinkMarker 数据，因而可能显示 LINK5 或其他旧数值；再次编辑保存也看不出变化。

编辑对局与编辑录像导出的卡片查询现在都显式包含连接数和连接箭头，保证生成、修改、回溯及录像能收到当前数据。没有更改原生普通对局的查询行为，也没有改动箭头选择排布。

实际 MDPro3 界面验证：自定义希望皇霍普，选择全部八个箭头，核心与场面均为 LINK8、箭头掩码 495；重新编辑取消向上箭头，核心与场面同步为 LINK7、掩码 367。修复前同一用例核心为 LINK8，但场面保留原卡掩码 2000。IL2CPP 与 Mono 框架下各 83 项核心断言通过，包括实际卡片查询报文携带全部八箭头。

该问题位于 MDPro3 刷新适配层，本次不改 YGOPro 核心。Mono 完整游戏启动仍需目标机器验证。
