# 0.3.1 切换视角时恢复原生连锁

复现：生成使用斩机径武作为超量素材的块斩机算子拉普拉斯，以获得的效果响应对方发动的效果；期间切换视角。核心保留正确的连锁，但 MDPro3 重建场面时清空原生连锁卡片列表，随后无效动画及效果记录可能显示在错误的卡片上。

修复：从场面重建消息读取按顺序排列的全部连锁，恢复原生卡片列表、卡号、控制方与连锁编号，并在效果记录上下文恢复后同步记录所用的同一连锁列表。不重新发送发动消息，不制造重复效果记录。仅编辑器会话生效。

验证：实际 MDPro3 中，强欲之壶 → 对方鲜花女男爵 → 径武赋予拉普拉斯的无效效果，切换视角两次后各连锁的卡片与数量一致；实际无效消息指向连锁 2 的女男爵，强欲之壶正常抽两张。真实核心另验证拉普拉斯①效果 → 对方女男爵 → 径武赋予效果，拉普拉斯①效果正常处理。Mono 组件编译通过，标准库 API 无缺失，217 个本体成员引用可访问；完整 Mono 本体运行仍未验证。

修复包含在 0.3.1 扩展和安装器中。旧存档不需要重做，切换视角或读取时会按当前核心连锁重新恢复。
