# v0.3.3 Mono 兼容修复

修复 MyCard Mono 本体安装后没有编辑器入口、卡片显示为空白的问题。加载阶段补全游戏组件的查找目录，部署与完整 System.Data 匹配的 Mono.Data.Sqlite，并关闭不兼容的 Unity 日志转接。原生游戏日志与编辑器日志仍保留。

卸载时，如果加载器由本安装器首次部署且没有其他插件，会恢复或移除本安装器管理的加载器文件；存在其他插件时保留共用组件。卡组、存档和录像不参与卸载。安装器保留原始文件备份并校验文件归属。

指示物入口仅显示于怪兽区中的怪兽，超量素材入口进一步限定为超量怪兽。对将要生成的卡片按目标区域和最终形态判断。

生成后立即因规则或效果离场的怪兽，不再导致按原位置查找卡片失败；界面会保留成功提示并说明实际去向。例如，罪 青眼白龙在没有表侧场地魔法时会被自身效果破坏，并非特殊召唤类型无法生成。

已验证完整 MyCard Mono 1.4.7-2 的启动、编辑器入口、卡片数据库、23 项素材与指示物界面检查、存档回溯、卸载后原生主菜单恢复；共享核心通过 139 项断言。原有 11 副卡组与本体 Managed 程序集未改变。不是所有卡片效果的穷尽验证。
