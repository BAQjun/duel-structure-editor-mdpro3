决构编辑器 MDPro3 安装器 0.3.3

支持 Windows 64 位：MyCard Mono 1.4.7-2 与 IL2CPP 1.4.8（安装前检查本体版本）。
关闭游戏，选择包含 MDPro3.exe 的文件夹，点击“安装 / 更新”。可以直接更新旧版，无需预先卸载。进入主菜单后选择“决构编辑对局”。

本版修复 Mono 版编辑器入口缺失和卡片空白：补齐加载时的依赖解析、匹配的 SQLite 组件，并关闭不兼容的 Unity 日志转接。未替换本体 Managed 程序集。
卸载时，如果加载器由本安装器首次部署且没有其他插件，会一并恢复本安装器管理的加载器文件；有其他插件时保留共用组件。卡组、录像和存档不参与卸载。

指示物入口仅在怪兽区内的怪兽上显示，超量素材入口进一步限定为超量怪兽。生成新卡时按目标区域与最终形态判断。
修复生成后立即离场的怪兽导致找不到卡片的异常，并保留生成结果提示。罪 青眼白龙在没有表侧场地魔法时会被自身效果破坏，编辑器现在会提示它生成后的实际去向；可以先放置场地魔法再生成。

已在完整 MyCard Mono 本体中验证启动、卡片数据库、编辑器入口、素材/指示物的生成编辑、存档与回溯，以及卸载后恢复原生主菜单。原有 11 副卡组与本体 Managed 程序集保持不变。不是对所有卡片效果的穷尽测试。
