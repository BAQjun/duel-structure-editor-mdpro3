决构编辑器 MDPro3 安装器 0.3.2

支持自动区分两类 Windows 64 位本体：
- 原先已验证的 IL2CPP v1.4.8 本体。
- 本次提供的 Mono 本体（Unity 6000.0.24f1，Assembly-CSharp.dll 的 SHA256 为 5c9f5fa0eeeabf1121b4d4120853f1236a3a8ae638e3e1e822701ed70c565246）。Mono 组件为适配验证版。

安装方法
1. 退出目标 MDPro3。
2. 运行“决构编辑器-MDPro3-安装器.exe”。
3. 选择包含 MDPro3.exe 的本体文件夹，点击“安装 / 更新”。安装器会按本体类型选择加载器和扩展，不把 IL2CPP 组件装到 Mono 本体。
4. 启动 MDPro3，在主菜单选择“决构编辑对局”。

Mono 验证范围
已按提供的程序组件完成编译、标准库接口检查、217 个 MDPro3 成员访问检查、128 项 Mono 64 位实际核心测试，以及安装／更新／卸载测试。
本机没有该版本的完整 Mono 游戏运行文件，因此尚未验证它在完整 Mono 本体中的实际界面启动。需在对方本机复测；异常时请在安装器点击“导出适配资料”，把生成的 ZIP 发回，包内会附带筛选后的加载器与编辑器启动信息。

Mono 适配细节
使用 BepInEx Mono 加载器，原本体 Managed 程序组件不覆盖。裁剪标准库的兼容框架放在 BepInEx/DuelStructureMonoRuntime，加载器从独立目录使用。访问适配器只在加载时开放扩展实际引用的成员，保留原本体文件；卸载会一同移除本扩展的访问适配器。

更新与卸载
再次运行安装器可更新。安装记录和原始文件备份保存在 BepInEx/DuelStructureInstaller。
卸载编辑器时恢复安装前存在的扩展文件，移除本次新增的扩展与访问适配器；保留加载器、全局配置、其他插件、卡组、存档和录像。
遇到不同版本的加载器、不同程序版本、游戏仍在运行等情况，会停止安装并提示，不强行替换。

适配资料导出
选择本体目录，点击“导出适配资料”。资料包含版本信息、Managed 程序组件，以及筛选后的加载器／编辑器启动信息，不包含卡组、存档、录像和账号配置。

单独的“MDPro3-Mono-适配验证版”目录供手动检查；通常请直接使用自动安装器。

0.3.0 修复：非连接怪兽的守备力不再被用作连接箭头。切换连接类型时清理无效位，连接数只按有效箭头计算，隐藏的阶级和守备力输入不参与连接属性校验。

0.3.0 修复：编辑对局和录像刷新主动请求连接数与连接箭头，修正自定义箭头保存成功但场面仍显示旧连接数和旧箭头的问题。已在实际 MDPro3 界面验证八箭头 LINK8 生成及已有卡片修改为 LINK7。

0.3.0 修复：自定义连接怪兽的箭头纳入核心的连接及互相连接关系，狮鹫等效果可正确判断其指向卡片的连接状态。真实脚本已验证鲜花女男爵通过自定义连接关系发动并破坏对方狮鹫。

0.3.0 新增：对应的融合、同调、超量、连接与仪式召唤履历；可搜索生成素材或选用现有卡，记录双方、来源和去向。额外卡组特殊召唤可选择对应四类召唤，仪式召唤不限制为手牌来源。保留正规召唤标记独立。素材检查与赋予效果按真实脚本初始化，已验证真红眼龙骑士通常素材数和 I:P 赋予抗性。

0.3.1 修复：切换视角或重建场面时恢复原生连锁列表与效果记录的连锁顺序，防止径武赋予效果的无效动画及记录指向错误卡片。

0.3.2 更新：安装器不再预填开发者游戏目录；构建与测试工具改用环境变量和 build-config.local.json，移除固定盘符与开发机路径。完整配置说明见源码 docs/路径配置与迁移.md。
